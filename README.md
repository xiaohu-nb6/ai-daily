# AI 前沿日报

一个纯静态的每日 AI 资讯站：左边读全文，右边看 100 字速览，阅读记录只存在你自己的浏览器里。右上角可在「纸感」与「科技」两套风格间切换。

## 线上地址

| 用途 | 地址 |
| --- | --- |
| 站点（GitHub Pages） | https://xiaohu-nb6.github.io/ai-daily/ |
| 源码仓库 | https://github.com/xiaohu-nb6/ai-daily |
| 每日更新运行记录 | https://github.com/xiaohu-nb6/ai-daily/actions |

站点由仓库 `main` 分支根目录直接发布，推送到 `main` 后约 30 秒自动重新部署，无需额外构建步骤。

## 每天怎么更新

`.github/workflows/daily-refresh.yml` 会在**每天北京时间 08:30** 自动执行：

1. 抓取 5 个 RSS 源（36氪 / 钛媒体 / TechCrunch AI / VentureBeat AI / The Verge AI）
2. 过滤与 AI 相关条目，自动归类为「模型发布 / 政策监管 / 行业动态」
3. 抽取式摘要裁剪到 100 字内，按发布时间倒序合并去重
4. 只有数据文件 `data/news.js`、`data/news.json` 有变化时才提交，其余不动

也可以在 Actions 页面点 **Run workflow** 手动跑一次。工作流只改数据文件，不会碰样式和逻辑，因此自动提交不会把本地改动冲掉。

## 打开方式

- **双击 `index.html`** 即可，页面数据和样式全部内联在本机，不联网也能看。
- 想用「刷新」按钮热更新数据，需要走本地服务器（线上 Pages 已满足，按钮可直接用）：

```bash
cd ai-daily
python -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000
```

## 每天怎么更新

### 方式一：跑脚本（自动抓，摘要为提取式）

```bash
python scripts/refresh_news.py            # 抓取并合并，默认最多新增 12 条
python scripts/refresh_news.py --dry-run  # 只预览，不写文件
```

- 源：36氪、钛媒体、TechCrunch AI、VentureBeat AI、The Verge AI。
- 只保留标题里明确谈 AI / 算力 / 机器人的条目，活动预告类稿件会被过滤。
- 自动归类到 `model` / `policy` / `industry`，自动打 3 个标签。
- **已有条目的 `id` 不会被改写**，所以阅读记录不会失联。
- 摘要直接截取原文首段，严格 ≤100 字，不改写、不编造；要更自然的摘要，可在 `classify()` 之后接一个 LLM 做改写。

### 方式二：手工加一条

在 `data/news.js` 的 `articles` 数组开头插入一条，字段照抄下面的说明，然后同步刷新 `data/news.json` 即可。

### 字段说明

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一标识，建议 `英文短横线-日期`，改 id 会让旧记录失联 |
| `title` | 标题，25 字以内最好看 |
| `category` | `model` 模型发布 / `policy` 政策监管 / `industry` 行业动态 |
| `date` `time` | `2026-11-03` 与 `12:08`，用于排序与展示 |
| `source` | 媒体名，可写多家 |
| `url` | 原文链接（详情页「阅读原文」） |
| `featured` | `true` 会出现在顶部「今日焦点」，同时只建议 1 条 |
| `tags` | 2–4 个关键词，会出现在焦点卡与详情页 |
| `summary` | **必须 ≤100 字**，右侧速览直接用它 |
| `body` | 正文段落数组，每段 60–150 字，2–4 段最合适 |

## 页面能力

- **三线并读**：模型 / 政策 / 行业分类筛选，标签上直接显示各分类条数；实时搜索标题、标签、正文。
- **搜索体验**：命中词在卡片与速览里高亮；输入框右侧有清除按钮；按 `/` 聚焦搜索框，`Esc` 清空；点顶部的关键词条可直接按该词筛选，再点一次取消。
- **详情抽屉**：点击卡片从右侧滑出，含速览、正文、标签、原文链接与同类资讯；支持 `#/a/<id>` 直接分享到某一条。底部有「上一条 / 下一条」与位置指示（如 `6 / 15`），也可用 `←` `→` 翻篇；抽屉顶部有一条随阅读进度推进的细线。
- **阅读记录**：打开即记录，可单条删除、一键清空，存在 `localStorage`（键名 `ai-daily.records.v1`），不上传任何服务器。
- **已读标记**：读过的卡片会淡一档并标注「已读」。
- **响应式**：≥1080px 为「资讯流 + 右侧速览」双栏；窄屏自动改为单栏。
- **速览末尾提示**：右栏速览列表不会硬切截断，底部固定一行「还有 N 条 · 向下滚动查看」，滚到最后变为「已到最末 · 共 N 条」。

### 右栏高度策略

- 右栏 `position: sticky` + `max-height: calc(100vh - 36px)`，内部「速览列表」用 flex 吃掉剩余高度，超出部分在列表内滚动，所以**面板底部不会再被挤出屏幕**。
- 代价说明：页面停在顶部时，右栏整体比首屏高出的部分（阅读记录面板下半截）会露在视口下沿之外，往下滚约 200px 后整列吸附到顶部、全部可见。这是长侧栏的常规行为，换来的是「滚动后右栏永远完整」。
- 「关于这份日报」放在页脚折叠，不占右栏高度。

## 风格切换

页头右上角有「纸感 / 科技」两段式切换：

| 主题 | 视觉 |
| --- | --- |
| **纸感**（默认） | 米黄纸纹、手绘墨线边框、便签阴影、楷体标题、暖黄记号笔高亮 |
| **科技** | 深空蓝黑底 + 冷调网格、青色/紫色极光、玻璃质感卡片与细描边、无衬线标题、等宽数字 |

- 选择写在 `localStorage`（键名 `ai-daily.theme.v1`），下次打开自动沿用；首屏前由 `<head>` 内联脚本读一次，不会出现白底闪一下。
- 也可用链接直接指定：`index.html?theme=tech` 或 `index.html?theme=paper`。
- 切换时给全局加 0.45 秒颜色缓动（`html.is-theming`），并同步 `<meta name="theme-color">`，手机浏览器地址栏也会跟着变色。
- 新增主题的做法：在 `style.css` 末尾按 `html[data-theme="xxx"]` 前缀覆盖变量与关键组件即可，`<body>` 上不需要挂类名。

## 排版规范（改样式前先看这节）

全站字号只用 8 档变量，组件里不再写死 px。改字号只改 `:root` 里这组值：

| 变量 | 桌面 | 窄屏（≤720px） | 用在哪 |
| --- | --- | --- | --- |
| `--fs-display` | 40px | 32px | 刊头主标题 |
| `--fs-title` | 33px | 26px | 详情页标题 |
| `--fs-h2` | 30px | 24px | 焦点卡标题 |
| `--fs-h3` | 22px | 19px | 面板标题、刊头日期 |
| `--fs-h4` | 19px | 19px | 卡片标题、数字强调 |
| `--fs-lead` | 15.5px | 15.5px | 焦点摘要、详情正文 |
| `--fs-body` | 13px | 13px | 列表正文、按钮、筛选 |
| `--fs-meta` | 12px | 12px | 日期、来源、标签等元信息 |

- **卡片等高**：`.card-title` 锁两行、`.card-sum` 锁三行（都是 `min-height` + `line-clamp`），所以 15 张卡片高度误差 ≤2px，栅格不再出现锯齿。
- **正文行宽**：抽屉宽 660px、左右内边距 56px，正文 548px ÷ 15.5px ≈ 34.6 字/行，落在中文舒适区。
- **日期统一**：所有条目日期由 `fmtShort()` / `stamp()` 输出 `11/03 · 19:44`，配 `--font-mono` 等宽字体；刊头日期固定 `2026 / 11 / 03`。数字统一开 `font-variant-numeric: tabular-nums`。
- **断行**：标题与正文加 `line-break: strict`，保证中文标点不落在行首。`word-break: auto-phrase` 和 `text-wrap: balance` 实测过，对这类中文标题无效甚至更差（会把「治理」拆开），已移除，不要再加。
- **例外**：只有三处装饰性字号写死——印章 17px / 13px、已读角标 10px，均已在注释里标注原因。
- **静态资源带版本号**：`index.html` 里引用的是 `assets/style.css?v=4`、`assets/app.js?v=4`。改完样式若浏览器仍显示旧效果，把这两个数字加一即可，不必清缓存。
- **不要用 `requestAnimationFrame` 驱动渲染**：搜索与末尾提示原先用 rAF 节流，在后台标签页/无头浏览器里会被节流，导致列表不更新。现在统一同步渲染，只在滚动这类非关键路径上用 `setTimeout` 防抖。

## 已知限制

- 本地文件模式（`file://`）下浏览器不允许 `fetch` 读取数据文件，所以「刷新」按钮会提示重新打开页面；走本地服务器则正常。
- 抓取脚本的摘要为提取式，适合快速扫读；重要资讯建议手工替换为人工摘要。
- 纯 CSS 无法保证中文标题不在词间断行（浏览器未提供可靠的中文短语切分），长标题偶尔会把「全程」这类词拆到两行。
- 资讯版权归原媒体所有，本站只做摘要与链接跳转。
